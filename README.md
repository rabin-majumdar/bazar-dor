# 🛒 বাজার দর | Bazar Dor

**Bazar Dor** is a Bengali daily market price tracking web application that helps users explore the latest prices of essential commodities in Bangladesh. Users can browse product categories, compare market prices, track price changes, and view detailed product information through a responsive and user-friendly interface.

🔗 **Live Demo:** [https://bazar-dor-gray.vercel.app/](https://bazar-dor-gray.vercel.app/)

## ✨ Key Features

- **📊 Daily Market Prices:** Browse the latest prices of essential commodities and track price changes.
- **🗂️ Product Categories:** Explore products by category, including rice, lentils, oil, vegetables, fish, and meat.
- **📈 Price Trend Tracking:** Discover products with rising and falling prices and view their percentage changes.
- **🔍 Detailed Product Information:** View product details, price summaries, and market-wise price information.
- **🔐 User Authentication:** Sign in or create an account using email and password, with Google and GitHub authentication support.
- **👤 Profile Management:** Update your profile name and upload a profile picture.
- **📱 Responsive Design:** Enjoy a user-friendly experience across mobile, tablet, and desktop devices.
- **🔄 Live Data Integration:** Fetch categories and product information from the market price API.

## 🛠️ Technologies Used

- **Next.js** — React framework for the application
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS** — Responsive styling
- **Better Auth** — Authentication and session management
- **MongoDB** — Database for user authentication data
- **Cloudinary** — Profile image uploads and image hosting
- **Lucide React** — Icons
- **Sonner** — Toast notifications
- **Vercel** — Deployment and hosting

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rabin-majumdar/bazar-dor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bazar-dor
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in a `.env` file. Use your own authentication, MongoDB, and Cloudinary credentials, along with the required application URLs.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
